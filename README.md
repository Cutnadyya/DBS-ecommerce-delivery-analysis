# DBS E-Commerce Performance Dashboard

## Project Overview
Project ini dibuat untuk menganalisis performa transaksi e-commerce pada tahun 2017 menggunakan dataset publik e-commerce. Analisis dilakukan untuk melihat pola transaksi pelanggan berdasarkan wilayah (state), tingkat kepuasan pelanggan, serta kontribusi nilai pembayaran pada setiap wilayah.

Hasil analisis divisualisasikan dalam bentuk dashboard interaktif menggunakan Streamlit agar data lebih mudah dipahami dan dieksplorasi.

## Dashboard Features
Beberapa fitur utama yang tersedia pada dashboard:

- Total Orders Overview
- Average Review Score
- Average Payment Value
- Customer Distribution
- Order Analysis by State
- Review Analysis by State
- Payment Contribution Analysis
- Monthly Transaction Trend
- Interactive State Filter

## Tools & Libraries
Project ini dikembangkan menggunakan:

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
